# Pattern Recognition 研究写作

按用户当前阶段工作。用户要求先学习时，先完成正式发表语料分类和全文精读，不提前替用户定idea或做实验。仅要求语言修改时，保持事实范围，不把整套新增实验当文字编辑的前置条件。

本技能的研究写作方法由已读取的CVIU/Information Systems/LaTeX经验迁移，来源与边界见 [经验及具体写作决策](references/craft.md)。它们不是PR接收因果规律。新增PR样本经验必须附正式DOI、实际阅读版本、页节表图及适用条件；只读摘要不能声称精读。

需要逐段学习时，读 [SAMOSA正式论文写作拆解](references/samosa-paragraph-study.md)：引言七段、相关工作十一段、方法的信息与梯度分工、三个结果段、图表及引用职能均按实际顺序定位。它是2024卷期、2023年上线的一个历史个案，段落数量和实验阈值不是PR规范；保留已发现的算法—正文不一致，不把已发表稿当零错误模板。

先把输入、输出、允许监督、困难条件、指标和预算写清。用“主张｜实际改动｜最近邻差异｜定位证据｜范围”约束全文。先修主张与证据的错配，再润色。真实结果、原作者报告、独立复算和待验证假设分开。

方法从整体数据流进入关键干预，明确符号/形状、固定与可学状态、执行时刻、损失及归一化、梯度或离散决策。资源增加必须披露；同训练步数不等于同运行成本。解释机制时选择能排除实际竞争解释的对照，不要求每稿机械堆满实验清单。

文字按读者问题组织：引言说明可见困难和最近邻窄缺口；相关工作按假设与监督分组；实验段落先回答问题，再给幅度与图表，最后说明范围。摘要和Highlights最后从已核实发现压缩，不能预填数字。结论按照PR要求讨论优势、弱点、用途和未来方向，不复述摘要。

图表由真实记录产生，统一比较条件、字体与语义编码；每图有明确判断任务。原图、裁剪规则、逐观测标量、聚合和绘图入口可追溯。语言修改后独立检查量词、因果、条件、公式、引文和数字；保留检查通过不代表语义一致。

正式要求查[PR官方指南](https://www.sciencedirect.com/journal/pattern-recognition/publish/guide-for-authors)：当前快照是单栏20–35页、摘要≤250词、数字引文和必需Highlights，存在附录计页冲突；可使用可用的pr-venue-gate但其安装不是本技能运行前提。
