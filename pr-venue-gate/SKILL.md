# Pattern Recognition 指南核查

先确认期刊身份及用户当前阶段。Pattern Recognition Letters 和 Pattern Recognition and Image Analysis 是不同期刊。把官方要求、出版商通用建议、已发表样本观察和自己的研究判断分开。

读取 [核实要求与冲突](references/requirements.md)。该快照在2026-11-09通过个人浏览器直接实读canonical指南；当日DataHub CLI GET为403，状态保持失败。新任务应刷新官方页面并记录实际访问方法、日期和可读范围。无法读取时用已知快照并注明日期，不把其他期刊或二手模板填成当前规则。

范围判断以原创模式识别问题及贡献为中心：说清输入、输出、监督、主要困难、最近邻差异及可复用知识。常规套用现成方法不因应用重要就自动适配PR。文章分布与样本写法不能推出接受率。

对稿件输出“要求｜官方位置｜稿件文件与位置｜通过/不满足/未核实｜具体动作”。优先核查专属格式、长度、摘要、Highlights、数字引文、cover letter三问、研究数据Option C和声明；不要把建议性措辞升级成自动拒稿条件。

指南内部冲突应保留双方位置。期刊专属规则优先于出版社通用许可；同级矛盾不能静默消失。当前附录计页矛盾可先通过含附录总页数≤35解决；确需例外时准备具体核实问题，不自行判通过。

存在DataHub常设规则时先映射其学术期刊模块，新增可复用来源按当地流程登记。只读指南不代表已进入投稿系统。技能不授权登录、发送邮件、公开稿件、修改作者或最终提交。
