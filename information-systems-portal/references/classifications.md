# Information Systems portal: classification list

Step 8 "Select your classifications" asks for **3 to 5** entries from this fixed list. Editors assign reviewers from them, so pick by the community whose members should review the paper. The list was transcribed from the portal on 2026-10-22 (submit.elsevier.com, new submission service). If the portal shows entries that are not here, the list has changed; update this file.

## Picks by paper type
| Paper type | Pick (3–5) | Avoid |
|---|---|---|
| Data cleaning, data quality, benchmark or evaluation audit (used 2026-10-22) | Benchmarking; Database Integrity; Data Integration; Database Systems; Relational Databases | Information Systems (whole journal), Data Analysis, Machine Learning when no learning method is proposed |
| Query processing / optimization | Query Processing; Database Systems; Relational Databases; Distributed Databases or Parallel Databases | |
| Data integration, schema matching, entity resolution | Data Integration; Information Integration; Database Systems; Similarity Measure; Linked Data | |
| Analytics / warehouse / semantic layer / metrics | Data Warehouse; Business Intelligence; Database Systems; Query Processing | |
| Data mining / ML over data | Data Mining; Machine Learning; Big Data Analytics; Data Science | |
| Process mining / BPM | Business Process Management; Process Modeling; Workflow Management; Enterprise Modelling | |
| Knowledge graphs / semantic web | Semantic Web; Linked Data; Ontology; Knowledge Management | |
| Streams / time series | Streaming; Time Series Analysis; Database Systems; Real-Time Systems | |
| Spatial data | Spatial Databases; Spatial Data Mining; GIS Databases | |

There is **no** "Data Quality", "Data Cleaning", "Reproducibility" or "Provenance" entry. For such topics use Database Integrity (constraints, consistency, repair) and Data Integration (the community that publishes cleaning systems such as Raha/Baran, HoloClean).
