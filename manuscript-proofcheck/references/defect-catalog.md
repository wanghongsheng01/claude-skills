# Defect catalog

Each entry: what the reader sees, the root cause, how the scripts detect it, and the fix. Rule ids
match `scripts/tex_lint.py` (T*) and `scripts/pdf_check.py` (P*). Entries marked *observed* were found in
a real compiled submission.

## Glyphs and symbols

### T01 / P01 Wrong glyph for the indicator 1 (*observed*, TopUp, ICDE 2027)
- Seen: `e = ⊮[A(t)=r]`, i.e. a turnstile-like symbol (U+22AE) instead of a blackboard-bold one.
- Cause: `\mathbb 1` or `\mathbb{1}` with amssymb/amsfonts. The `msbm` font only has upper-case
  letters, so the slot for "1" holds an unrelated relation symbol.
- Detect: source regex `\mathbb\s*\{?\d`; PDF text contains U+22AE.
- Fix: `\usepackage{dsfont}` and `\mathds{1}`, or `\usepackage{bbm}` and `\mathbbm{1}`, or plain
  `\mathbf{1}`. Define one macro (e.g. `\newcommand{\ind}{\mathds{1}}`) and use it everywhere.

### T02 Unicode characters in source compiled with pdfLaTeX
- Seen: missing characters or compile errors (×, –, ’, ≤ typed directly).
- Fix: use LaTeX commands (`$\times$`, `--`, `'`, `$\le$`), or compile with a Unicode engine the venue allows.

## Bibliography

### T03 / P03 Dash instead of repeated author names (*observed*)
- Seen: `[15] ——, "Optimized stratified sampling …"` directly after an entry with the same authors.
- Cause: IEEEtran.bst replaces an author list that repeats the previous entry's with a 3-em dash by
  default (`CTLdash_repeated_names = "yes"`). This is legal IEEE style, but readers often take it for a
  rendering error, and it hides authorship when entries are cited out of order.
- Detect: IEEEtran bibliography style without a BST control entry; PDF reference line starting with a
  dash.
- Fix: add to the `.bib`
  ```
  @IEEEtranBSTCTL{IEEEexample:BSTcontrol,
    CTLdash_repeated_names = "no"
  }
  ```
  and put `\bstctlcite{IEEEexample:BSTcontrol}` right after `\begin{document}`. For biblatex use
  `dashed=false`. For other `.bst` files, check their options.

### T04 "et al." or "and others" in a self-citation
- Cause: the bib entry was written before the author list was known.
- Fix: list every author. Under double-blind review, use the venue's anonymisation rule instead.

### T05 Unverifiable or impossible entries (*observed*: an "ACL 2026" DOI for a 2024 arXiv paper)
- Cause: bib entries copied from memory or generated by a model.
- Detect: the year is later than the current year, a DOI prefix does not match the venue, a "2026"
  publication of a known arXiv paper. The lint only flags candidates; online verification decides.
- Fix: replace the entry with the record from DBLP, the ACL Anthology or the publisher. If no published
  version exists, cite the arXiv version.

### T06 Entry fields
- Missing `year`, missing `pages` for journals, `howpublished` misused for published work, duplicate
  keys, inconsistent venue abbreviations (`Proc. VLDB Endow.` vs `PVLDB`). Pick one abbreviation
  scheme for the whole list.

## Theorems and proofs

### T07 Foreign QED box with IEEEtran (*observed*)
- Seen: an open square □ at the end of each proof, unlike the closed box of IEEE papers. Readers flag
  it as a stray glyph.
- Cause: `amsthm` loaded with IEEEtran. amsthm's `proof` uses `\openbox`, and the IEEEtran
  documentation advises against amsthm because the two theorem implementations conflict.
- Detect: `\documentclass{IEEEtran}` together with `amsthm`, or `\begin{proof}`.
- Fix: drop `amsthm`. Keep `\newtheorem{theorem}{Theorem}` (IEEEtran formats it), and replace
  `\begin{proof}[Proof sketch]…\end{proof}` with `\begin{IEEEproof}[Proof sketch]…\end{IEEEproof}`.
  Remove `\qedhere`; IEEEtran places the mark itself (`\IEEEQEDhere` if needed).
- Other classes: acmart and llncs already load their own proof environments, so do not load amsthm on
  top of them.

## Title, authors, front matter

### T08 / P08 Hand-made line break in the title (*observed*)
- Seen: a four-line title with a two-word line ("LLM Labels") and a one-word last line ("Data").
- Cause: `\\` inside `\title{}` forces a break where it fits one page width but not the class's.
- Fix: remove `\\` and let the class break the title. If a break is required, use `\\` only at a
  phrase boundary and check the compiled result.

### T09 TODO, placeholder or coloured draft text left in
- Detect: `\todo`, `TODO`, `XXX`, `\textcolor{red}`, `[citation needed]`; PDF spans in non-black colour.

### T10 Author block
- Must match the submission system exactly (order, spelling, affiliations). Use the class's macros
  (IEEEtran: `\IEEEauthorblockN/A`, `\IEEEauthorrefmark`, and `\thanks` with
  `\IEEEoverridecommandlockouts` for a corresponding-author note).

## Math layout

### T11 Tall inline math pushes into the previous line (*observed*)
- Seen: the overline of an inline `\sqrt{\sum …/…}` touches the text line above, which looks like
  underlining.
- Cause: inline radicals, `\frac`/`\dfrac` and big operators with limits enlarge the line height.
- Fix: move the formula to a display, or rewrite inline as `(\cdot)^{1/2}` with `\sum\nolimits` and a
  slash fraction.

### T12 Display whose continuation floats far right
- Cause: `multline` right-aligns its last line. With a short first line in a narrow column, the
  formula looks broken.
- Fix: `align*` with `&` at the left of both lines and `\quad` before the continuation, or `split`.

## Spacing and page budget

### T13 Spacing hacks (desk-reject risk)
- Negative `\vspace`/`\vskip`, `\baselinestretch` < 1, `\setlength{\textheight}`, `geometry`,
  `\titlespacing`, `\abovedisplayskip` changes, `\small` around body text, `\linespread`.
- Fix: remove them and cut text. Never trade layout rules for space.

### P13 Page budget
- Count body pages the way the venue does (e.g. the main text up to the references, or everything).
  `pdf_check.py --body-limit N` compares the page holding the reference heading with N.

## Cross-references and text

### T14 `\cite`/`\ref` without a non-breaking space
- `word \cite{x}` can break the line before "[12]". Use `word~\cite{x}` and `Table~\ref{t}`.

### T15 Unreferenced float or label
- Every figure, table and algorithm label should be `\ref`'d in the text.

### T16 Inconsistent spelling variety
- Mixed `labelling`/`labeling`, `-ise`/`-ize`, `modelling`/`modeling`. Pick the venue's variety.

### T17 Repeated word
- "the the", "a a", "of of", also across a line break in the source.

## Fonts and PDF

### P17 Type 3 or non-embedded fonts
- Usually from matplotlib (set `pdf.fonttype = 42`) or old figures. IEEE PDF eXpress and some
  publishers reject non-embedded fonts.
