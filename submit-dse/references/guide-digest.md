Conflicts inside the official text, and how this skill resolves them:
1. Citation style: guideline examples use name-year, all 39 sampled articles print numbers. Use numbers; alphabetize the list so that both readings are satisfied.
2. Format: "should be submitted in Word" versus LaTeX for mathematical content. LaTeX is accepted.
3. Declarations heading: "Statements and Declarations" in one section, "Declarations" on the title page in another. Under double-blind review they go on the title page.
4. Supplement file header asks for author names, the double-blind rule forbids them. Double-blind wins for review.
