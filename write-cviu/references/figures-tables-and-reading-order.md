# 图表与读者的判断顺序

本文件为写作与呈现建议。依据是 [CVIU 范例](examples.md)、`results-presentation-review` 的经验及实际科研图表设计原则；图数、配色和排版示例不是期刊硬性规则。

## 给每个对象一个科学作用

在画图前说清读者要判断的对象：机制在哪里改变数据流、哪些控制相同、哪个量变化、这种变化与目标误差有什么关系。方法图解释执行结构；主比较表展示完整条件；机制图回答原因；定性图让人直接看到真实输出。不要让同一张排名表承担所有用途。

读者应从图表标题、图注首句和局部标签看懂比较，再到正文读解释。图注可以先说观察，也可以先说明所比较对象；不要把过强的优越性判断强塞进图注。方向、单位、范围、误差条含义及必要条件应能定位。协议过长时放在设置中并明确指向，而不是按一个固定词数删掉关键条件。

## 定性图：全景与可辨识细节互补

- 优先复用已经生成并核验的真实实验图，确认样本、视角、帧、方法顺序、尺寸和颜色处理。
- 人体或目标在全景里很小时，用同一规则产生的前景放大图补充正文。保留全景参照或明确指向，给出裁剪规则及对应关系。补充里的有价值图不必永远留在补充。
- 放大图应回答真实差异，不以视觉上最好看的结果重新选样。各方法使用同一裁剪框，保留未处理输出和生成脚本。
- 显示缩放不等于更高的评价分辨率。方法图的美化与实验图的处理是不同工作，不生成或修饰伪实验细节。
- 在最终页面尺寸和灰度下检查标签、人体细节、线型及对照。原图正确但缩进版面后看不清，也需要修复布局。

## 量化表：数值完整，解释集中

- 将每个指标的方向、单位和聚合单位写清。多个相机、帧或动作与训练种子之间的嵌套关系不能用一个含糊的 n 代替。
- 所有策略保留一致行序、精度与比较范围。数值标记由结果与指标方向生成；如果按完整精度排名，须与打印后的并列外观协调。可增加精度或说明规则，不能为突出本方法改名次。
- 最优、次优和赢家数量是可选阅读辅助，不是统计结论。近零差异与少量种子下通常优先显示配对差值及不确定性，而不是堆赢家计数。
- 若各分组平均已经在表中，就不再添加一个改变权重的“总平均”。PSNR 的逐图平均与先平均 MSE 再换算不同；原聚合不能因美化而改变。
- 表太宽时先缩短列名、分组或拆表，在可读字号下排版，不用缩小整张文字表掩盖溢出。
- 由脚本生成的表只修改生成器并重建；纯 LaTeX 手写表则保留与原数据的映射。检查改变的是展示还是计算。

## 按比较逻辑排列

同任务、同预算的主结果与扩展相机表放在一个完整讨论单元；敏感性图紧跟所改变的参数，匹配状态的操作前/后/拟合后结果紧邻解释。保持首次正文引用顺序与编号一致，章节搬迁后重新核对所有“Table n”“Figure n”和相对位置描述。

机制研究可按“决策变化→操作影响→拟合结果”组织，其完整性能结果依然必须显眼、可定位。若主要贡献是新的重建系统，则通常先说明主比较，再用消融与机制解释。范例提供备选结构，不替作者作机械选择。

## 最终实物检查

对最终 PDF 的每页目检，记录具体图表缺陷，修正后重编译受影响稿件。干净解压编译源码，核对文本、图表与资源完整性。自动警告需要实际图形判断：正常的数值列间距不是拉伸的正文，文字提取异常也不自动证明 PDF 字形错误。已验证且未变化的原始数字无需因版式调整重新训练。
