# 从研究问题到可区分的证据

本页是实验设计建议，不是 CVIU 强制实验清单。按当前中心主张选择最少但有效的对照；没有执行的实验保留为方案。

## 主张与测试的对应

|中心主张|可以直接回答它的证据|需要控制的替代解释|
|---|---|---|
|渲染外观改善|完整主体与预定义细节区域的匹配图像指标、真实全图及同位置裁剪|测试视角/帧、分辨率、背景、裁剪、曝光与相机配准|
|语义先验有效|同预算有/无语义指导，直接观察部位边界或混淆情况|标签质量、额外预训练监督、更多训练或参数|
|运动学关系有价值|空间关系对照运动学关系，必要时加结构打乱控制|图规模、特征维度、采样、关系数量和增密点数|
|分配规则更有效|同最终点数或同资源预算，记录分配位置与渲染结果|增加表示容量本身造成提升|
|几何/结构更准确|与任务一致的几何真值、关键点或可校核结构量|相机误差、姿态初始化、外观拟合掩盖错误形状|
|鲁棒或可泛化|明确退化、域或未见动作划分，按冻结范围评估|测试集调参、训练暴露、仅挑选漂亮案例|
|更高效或可实时|同硬件、分辨率、精度与计时边界的训练/推理记录|缓存、预处理、点数、外部模型成本遗漏|

当结论是某机制没有作用时，必要的正对照可以检查评测是否能检出已知变化；一次未检出不自动证明能力不存在。分箱或条件分组图表应标注每组样本数和独立单位。

冻结测量对象比堆指标更重要。记录单位是 subject、场景、相机、序列还是随机种子；逐帧数据可以描述序列内部变化，不能凭数量大就宣称有同等数量独立重复。

## 方法到执行的最短链路

为新增组件保存：输入与形状、输出、固定/可学习状态、执行时机、如何影响参数或离散决策、一个有/无干预检查。连续损失可检查目标参数梯度与真实更新；离散控制可检查候选/选中 ID 和子点数量。数值进入总 loss 并不自动证明它影响了训练。

用少量真实样本先验证接口和机制，再投入完整比较。小样本机械检查、合成单元测试和正式数据集结果分开报告。修复改变了实际算法时，应重新生成受影响结果；不把新代码签名绑定到旧数字。

## 展示视频与压缩素材的诊断

先确认标签、来源、哈希、解码像素格式、帧数、时间戳与空间对应。时间戳相同只能支持时间索引匹配，不能独自证明同一相机、裁剪或空间配准。

全图误差可能被背景主导。需要敏感性检查时，可使用仅由 GT 决定且对所有方法相同的固定裁剪，报告规则；此裁剪不是人工标注的真值分割。保持原图和原指标，任何对齐后分析另外报告，不挑选最有利变换。

如果预测存在整体位置差异，记录观察并区分可能解释：预处理、相机/姿态条件或模型误差。缺少生成协议时不能确定原因，也不能将压缩展示素材的分数直接转述为统一协议下的模型性能。更不能把训练视角展示片段充当未见视角验证。

## 结果段落模板

用自然语言回答问题，再给关键数字与解释。例如：“在设置 P 中，M 相对 B 的感知误差降低 X，而结构相似度仍由 C 取得最高值。完整比较见表 T。此结果支持本节的外观质量观察。”仅在实际计算和完整表格支持时使用对应内容。

累计消融描述条件性变化；独立贡献、交互和因果归因需要相应对照。只知道均值时保留描述性比较，不补造标准差、置信区间或 p 值。
