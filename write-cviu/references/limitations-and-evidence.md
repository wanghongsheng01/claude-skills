# 限制的准确位置与可执行补证

这是从公开论文和研究方法推导的写作建议，不是编辑部录用规则。读者能观察已发表论文的呈现方式，但不能从发表状态推断审稿人因哪句话接受论文。

## 先找事实，再决定位置

建立登记：原句及页码／它影响哪个主张／已有证据／处理动作／英文候选句／仍需证据。每项只采用实际可支持的范围。

|内容|适合的位置|处理原则|
|---|---|---|
|主比较结果不利于新机制|摘要关键发现、完整主表和结果解释|保留方向和量级，不改成优势或等效|
|输入监督、初始化、测试单位|方法与协议，摘要需要时点明|用肯定式定义实际任务，避免反复列未研究任务|
|数值随机性影响排序或结论|相应结果附近、补充明细|不能藏入一般“未来工作”；区分不同种子与相同种子重跑|
|另一个任务未评估|范围段或讨论|只在它确实约束本文承诺时说明，不无限列举未做事项|
|执行日志、恢复历史、内部审批|研究记录或复现包|论文仅保留解释方法与结果所必需的出处和版本|
|新参数仅改变离散决策，尚无拟合输出|方法诊断与后续实验计划|不能把决策差异写成视觉质量提升|

## 一段话的组织方式

先陈述实际观察，再说明它成立的条件，最后给出对设计或解释的影响。例如：“Under protocol P, the intervention changes decision D, while the measured output changes by E relative to B. This identifies C as the next factor to test.” P、D、E、B、C 都必须来自实际证据或明确标为待检验假设。不要把没有优势改成“证明无效”，也不要把小差异改成“等效”。

边界可以写成正面的任务定义。例如，将“We do not evaluate arbitrary future times”改为“We evaluate held-out views at the observed timestamps”，但前提是准确保留时间范围，且摘要、题名没有承诺未见时间泛化。必要的信息必须在读者判断相关主张时可见，不能通过挪到补充隐去。

范例的可迁移结构见 [examples.md](examples.md)：VDGS 将任务收益与专用反射任务的边界相连；holistic triangulation 将未见动作与具体实验相连；NeRFtrinsic Four 区分初始化条件和相机估计指标。不要复制这些论文的评价性形容词、较强概括或选择性汇总方式。特别是开销，应先计算同条件差值再判断如何表述。

## 允许增量实验，但每一项都要改变判断

|动作|何时有价值|最少记录|
|---|---|---|
|增加或补充|关键机制缺少到输出的证据，或存在可区分的替代解释|假设、干预、对照、预算、独立单位、指标、停止条件|
|替换|旧协议存在确定错误或不回答中心问题|原结果和更正原因、受影响主张、新协议版本|
|合并／移补充|几个实验重复回答同一问题，或逐样本详情妨碍主线|完整结果入口、合并规则、主文必要摘要|
|删除|重复、无效测量或与范围无关|删除原因与存档位置；不得因为数值不利而删除|
|缩小主张|当前证据只能支持更窄但仍有价值的结论|同步更新题名、摘要、贡献、图注和结论|

测试结果已见之后增加的分析，应标为探索性；可另冻结未查看的独立确认集。改变门控、阈值、算子或渲染器后，受影响的训练或评价比较需要同条件重跑；纯同状态离线诊断则重算对应决策，无需自动扩为全量训练。不要把新 GPU 与旧硬件的绝对结果直接拼成方法收益，先验证实现一致，再在同一设备配对比较。

设两类停止条件：资源预算上限与可回答问题的完整度。完整度应由预设测量、覆盖和有效运行决定，不以得到有利符号为条件。必要时先用小规模开发样本评估方差和成本，确认实验在冻结前确定重复数；不得逐次看测试分数直到达到显著或最好。

## 交付和核验

建议实验必须标“计划”，完成实验必须有实际日志与输出。若用户先审计划，不提前实施。实施后对每条主张闭环：问题 → 变化 → 证据 → 范围；核验新增或删减是否改变结论。比较原稿与新稿，确认没有把负结果、已知混杂、协议改变、授权事实或论文的实质范围通过语言处理抹去。
