# Submission-prep commander — prompt checklist

Use this as the reusable checklist (and as the backbone of a prompt) when the author says “prepare this paper for the submission window.” Tick every item in the Chinese report. Official pages win.

## Packet integrity

- [ ] Local PDF is a fresh compile, 0 errors, body pages within the venue limit.
- [ ] Author's Overleaf PDF (if any) matches the local latest page by page; otherwise reconcile first.
- [ ] Title, abstract, author block and headline numbers in the form packet are copied from that PDF, not from an older draft.
- [ ] If the abstract changed since a previous form draft, the portal abstract is flagged for re-copy.
- [ ] Numbers, macros and tables come from the same final experimental source.

## Skill pipeline (auto-invoke)

- [ ] Venue official pages re-read; access date recorded.
- [ ] `paper-presubmission-review` (including 邓-会议 items) run; SOTA 总表 verdict stated.
- [ ] `results-presentation-review` / `results_lint` run.
- [ ] `manuscript-writing-review` and `manuscript-proofcheck` run.
- [ ] `submission-integrity-check` run (every reference exists).
- [ ] Venue form skill run (`icde-cmt-submission` or equivalent).

## Form and what only the author does

- [ ] Paste-ready English fields (title, abstract in Unicode, relevance / similar, artifact paragraph, AI declaration).
- [ ] Chinese walkthrough of each box and tick, with live limits.
- [ ] Reminder: every co-author's ORCID and conflicts in the portal; missing one is often a desk reject; after creating the record they may need to log in again.
- [ ] Reminder: the author submits; the agent does not, unless explicitly authorized for that exact click.
- [ ] Author list frozen; no unauthorised public repo or visibility change.

## Second author and advisor comments

- [ ] Briefing document: problem, prior methods, gap, our method, experimental standing.
- [ ] Advisor comments evaluated against the official CFP and the table's actual intent; accepted ones absorbed into skills.

## Portfolio, time, safety

- [ ] Same-venue overlap and official author caps checked.
- [ ] Parallel work is in a separate session; current work was not stopped.
- [ ] Author-only steps have a 任务说明书 (what, why, exact path, done-criterion).
- [ ] Official deadline stated in the author's timezone.
- [ ] No credentials or raw enterprise data in the packet; public data supports the conclusions.
- [ ] Historical “acceptance over honesty” wording was not followed; losses stay visible and explained.
