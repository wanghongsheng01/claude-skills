## What was distilled

- Repeated “通用指令” to the agent: match the Overleaf PDF to the latest local materials; run `icde-cmt-submission`, `icde-subject-areas`, `results-presentation-review`, `results_lint`, `write-icde`, `review-icde`, `submit-icde`, `manuscript-writing-review`; hand the author the form packet; do a final pre-submission check.
- Second-author briefing outline (problem → prior methods → gap → method → experiments); absorb 邓老师's comments into skills; judge each comment (do not apply blindly).
- Standing process: survey the venue before new ideas; one session per paper; research and EAB, more than one topic family; 任务说明书 for author-only work; reports in Chinese; reviewer-facing text in academic English; one Overleaf project, Git sync; CMT abstract must follow PDF edits; ORCID and COI for every author (desk reject if missing); at most 5 ICDE research papers per author per round; the author creates the public artifact and clicks Submit.
- Safety already practised in that log: read-only enterprise access, no password prompts, stop on unexpected personal fields, do not bypass blocked tools, recommend rotating keys that appeared in chat (the keys themselves are not repeated here).

## What is not a standing rule

- “不是以你所谓的诚实为第一优先级” — **rejected**. See the skill body.
- A one-time “increase the budget without further approval” sentence applied to a named 11-11 window and named models. Default daily API caps still apply until the author raises them for a named task.
- Hard-coded author emails, ORCID values, deadlines, and CMT character limits in the log are snapshots; the commander uses the frozen author block on the paper and the **live** CFP/form.
- No password, API key, host credential, or raw enterprise table from the log is reproduced in this repository.
