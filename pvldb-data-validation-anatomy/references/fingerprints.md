# 四篇范文的量化指纹（逐项对照官方 PDF 计数）

缩写：**SPA** = SPADE（PVLDB 17(12), 2024）；**DEE** = Deequ（PVLDB 11(12), 2018）；**YTC** = YouTube CI/CD（PVLDB 18(12), 2025）；**SCO** = Scorpion（PVLDB 6(8), 2013）。
口径：字数为「正文≈」（只计每行 ≥6 词的行，剔除浮动体，约低估 3–5%）；占比以正文词数为分母。轨道：SPA、DEE 的 PDF 未标轨道（DEE 通常被认为是工业稿，未核实）；YTC 属工业场次（二手信息）；SCO 为常规研究论文形态。三篇带工业/部署色彩，所以**下表是"已发表的下限与形态"，不是研究轨道的上限**。一般 PVLDB 分布（12 篇）见 `vldb-exemplar-sop/references/02_quantified-bars.md`。

## 3. 对研究轨道候选稿的标尺（据此判 met / partial / gap）

以下是"至少达到范文中位数，并在范文共同短板上超过范文"的组合标尺：

| 要素 | 标尺 | 判定 |
|---|---|---|
| 正文页 | ≤12（Vol 20 Regular，不含参考文献） | 超出 = 阻断 |
| 摘要 | 150–220 词、7–8 句；≥2 个数字且全部可在正文表/图中逐字找到并带口径（百分点/相对值） | 缺数字 = partial；数字不可追溯 = 阻断 |
| Intro | 0.9–1.5 页；4 条贡献，每条带节号与证据展品编号 | 无节号 = partial |
| 形式化 | 问题定义 + 至少 1 个带证明的定理（若稿件声称保证，如零误报、检测完备、预算内最优） | 声称保证但无定理/证明 = 阻断 |
| 方法 | 55–65% 正文；每个组件有"朴素 → 不足 → 设计 → 理由" | |
| 实验 | 20–30% 正文；≥5 件实测结果展品；≥3 个数据集/工作负载（或 1 个真实 + 可控合成）；显式实验问题 | 展品 <5 = major |
| 对照 | ≥1 个外部已发表方法或其忠实重实现 + 自家弱化变体/消融 + 被排除的平凡基线的说明 | 只有稻草人 = 阻断（同 `vldb-exemplar-sop` G8） |
| 统计 | 重复测量并报告离散度或置信区间（四篇范文都没有，研究稿应超过） | 无 = major |
| 负结果 | ≥1 处带数字的自家不利结果 + 机制解释 | 无 = 阻断（同 G2） |
| RW | 4–5% 正文，3–5 个主题段，每段以技术对比句收尾；同题代表系统必须引用 | 漏引同题系统 = major |
| 参考文献 | ≥35 条（中位数），5 年内 ≥50%，DB 核心 venue ≥30% | <19 = major；<35 = partial |
| 首页 | 有首页图（系统流程或真实数据动机）+ artifact 实链接 | 缺 artifact = 阻断（同 G4） |
