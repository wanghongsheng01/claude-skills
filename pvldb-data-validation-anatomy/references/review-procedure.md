# 逐节、逐段审查程序（Gate B：与已发表范文对齐）

审查对象是一份**锁定版本**的候选稿（LaTeX 源 + 编译 PDF）。每条规则输出一行：

```
<规则ID> | met / partial / gap | <文件>:<行号>（PDF 页/栏） | 稿件现状（一句） | 范文证据（论文缩写 + 节/页） | 要求的修改 | 验收测试
```

- 证据必须精确到 `sections/intro.tex:42` 这样的 **文件:行号**，并附 PDF 页码；没有定位的判定无效。
- met = 规则完全满足；partial = 部分满足或满足但有瑕疵；gap = 没做或做反。
- 每条 gap/partial 必须写成可验收的修改请求（见 `two-gate-loop.md` 的修改请求格式）。
- 范文缩写：SPA = SPADE，DEE = Deequ，YTC = YouTube CI/CD，SCO = Scorpion。详细证据见各 `references/<paper>.md`。
- 先做 Gate A（`two-gate-loop.md`）。Gate A 未过时，Gate B 照常审查，但结论里 Gate A 的问题排在最前。

## 0. 准备：锁定与计数

1. 记录 PDF SHA256、源码包 SHA256、页数、编译日志中的 overfull/undefined 警告。
2. 按 `fingerprints.md` 第 1 节的行逐项计数（页、各节词数、图、表、结果展品、定义/定理、对照组、数据集、指标、参考文献及年份/venue/自引）。计数方法与范文一致：按栏裁切、只计 ≥6 词的行。
3. 抽出：摘要与结论中的全部数字；贡献 bullet；所有"we guarantee / always / never / zero / optimal / first"类断言；所有 `\ref`。

## 11. 阻断条件（命中任一 → Gate B 结论为 NOT CLEAN，不得批准投稿）

1. 正文超过 12 页（Vol 20 Regular，参考文献除外），或违反 `submit-pvldb` 中的任一硬规则。
2. 摘要或结论中有任何数字在正文表/图中找不到、口径不一致，或首次出现在结论（A3、C2）。
3. 稿件声称保证（零误报、完备检测、预算最优、soundness 等），但没有带编号的定理及其证明落点，或定理前提在实验中未被检查（P6）。
4. 所有对照都是稻草人：没有外部已发表方法（或其忠实重实现）也没有自家弱化变体/消融（E4，同 `vldb-exemplar-sop` G8）。
5. 对照不公平：同一预算/输入/硬件不一致，或对照的实现被本轮修改拖慢而未修复（E5）。
6. 全稿没有任何带数字的自家不利结果（E11，同 G2）。
7. 头条结果来自 DEV/调参数据，或冻结后的 TEST/gold/scorer 被改动（E16）。
8. 贡献 bullet 中有任一条在正文没有对应节或没有对应的实测证据（I8）。
9. 首页 artifact 块为空、占位或个人主页（同 G4）。
10. 交叉引用/表格行号指向不存在的对象，或同一量在两处数值不一致（F7、P8）。
11. Gate A 有任何 FAIL / MISSING / 未在已证界限处的 PARTIAL 行（见 `two-gate-loop.md`）。

## 12. 报告格式
