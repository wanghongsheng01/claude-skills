这些材料是实取出版者存入的 Crossref 题录后形成的可复用学习结果。共3846条：主窗2024-01-01至2026-11-09的3781条，加滚动36个月前缀2023-11-10至2023-12-31的65条。主窗排除60条编辑名单/勘误/撤稿/撤除/社论及47条缺卷号记录，得到**3674篇卷期日期元数据队列**（2024：850；2025：887；2026：1937）。

全部主队列只有月级印刷日期，没有在线发表日期。因此不能称为“截至11月9日已正式发表VoR的完整全集”。最新月份2026年11月的432条单列；排除它们后保守队列为3242条。加入2023末的滚动口径为3738条；缺卷号题录可用于敏感性而不能自动获得正式状态。

## 已学到的结构

任务、科学问题/学习设定、方法、应用领域是四个独立轴。标题规则不强制主标签，保留多标签和未知。科学问题/设定信号前三及第四是：有限监督/自监督/无监督489、多视图/多模态458、效率/可扩展性321、迁移/泛化255。前四顺序在去除11月、滚动窗口和包含缺卷号的口径下保持。

这不是“真实科学问题全排名”或期刊接受率。科学问题/设定轴有1915条（52.12%）无法仅凭词典确定。即使命中“multimodal”，也不能仅从题名认定核心瓶颈是一致性；“self-supervised”可能只是方法。题名观测匹配数不是实际主题数量的有保证下界，因为既可能漏检也可能误报。

年度题名占比可帮助选择精读顺序，例如多视图/多模态从8.12%（2024）到11.95%（2025）、14.61%（2026至11月）。这种变化还可能受出版编排、索引和类别粒度影响，不证明编辑偏好。方法信号仍包括注意力/Transformer、图/超图、生成/扩散、张量/低秩、核与模糊方法；不能把最新模型名称当作科学问题。

## 人工检查与修正经验

固定抽样为每年按DOI SHA256排序取40条，共120条；独立审阅者实际复核其中每年前20条，共60条challenge题名语义。54条没有发现明显题名信号错误、2条明确漏标、3条可能漏标、1条弱问题推断。此结果不是90%总体准确率，也不是全文gold；独立复核之后未围绕这两条漏标继续调词典。

早期检查修正了三个泛词陷阱：frequency-domain不等于domain adaptation，generative adversarial不等于安全对抗，machine learning不等于工业机器领域。出版关系检查还发现题名为REMOVED的1篇原来未被排除，最终主队列从暂定3675修正为3674。该记录不在120条抽样和60条复核中，因此独立复核样本没有改变。勘误与撤稿是不同状态，不可把更正notice直接当作原文撤稿。
