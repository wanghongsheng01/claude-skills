# DASFAA 2027 Desk-Reject Screen Checklist

Check before scientific review (checked against DASFAA 2027 CFP on 2026-11-25):
- [ ] **Template**: Springer LNCS (`\documentclass[runningheads]{llncs}`), A4 page size, `splncs04` bib style.
- [ ] **Page Budget**: Strictly `≤ 16` pages TOTAL including references and any appendices.
- [ ] **Abstract**: Strictly `≤ 200` words, plain academic summary, zero citations, zero self-negation.
- [ ] **Strict Double-Blind**:
  - [ ] Author block is `Anonymous Author(s)` / `Anonymous Institution`.
  - [ ] Zero leaks of real author names, affiliations, corporate names (e.g., Loctek), or personal GitHub usernames (`wanghongsheng01`) in text, figures, footnotes, bib, or PDF metadata.
  - [ ] Artifact URL uses neutral anonymous host (`anonymous.4open.science`) and has been verified live & clean.
- [ ] **Database Scope**: Clear data-management / query / contract / data-quality / integration formulation with peer-reviewed DB citations (SIGMOD/VLDB/ICDE/DASFAA/TKDE).
- [ ] **No Layout Hacks**: No negative `\vspace` hacks, no altered margins, no font shrinkage below LNCS defaults.
