# Pattern Recognition 独立预审与修订

先记录稿件、数据、代码版本及用户授权阶段。用一段话复述最有证据的贡献；区分作者报告、原文可见证据、独立复算、源码核对和判断。每个实质发现带页节表图或文件定位。

按以下问题检查，选择与中心主张有关的项：

1. 标题、摘要、任务设置、监督与测试是否说同一问题；实际测量是否对应声称能力。
2. 最近邻差异是否来自原始文献，是否仅改名或常规组合；额外数据、参数、预训练与算力是否说明。
3. 方法公式/符号、采样、梯度、离散选择和运行配置是否一致；新代码是否被错误关联到旧结果。
4. 主表与最强相关基线是否可比；作者报告与统一重跑是否分开；同step是否被误称同成本。
5. 消融是否真的识别关键干预；简单替代是否足以解释；累计加入不能自动作独立因果归因。
6. 划分、调参和独立统计单位是否合理；同主体帧、时间点和同种子重放不能膨胀样本量。
7. 摘要、正文、表格、第二指标、不同数据集与失败样例是否一致；不利结果和适用范围是否保留。
8. 图像比较是否同视角/时刻/裁剪；图表能否追溯逐观测数值、配置及聚合；精确复算是否固定运行时。
9. 当前PR官方要求是否满足；格式就绪、科学证据闭合、作者批准和真正提交是不同状态。

将每项发现写成 **位置→影响→具体动作→最低必要证据→完成标准**。动作可为核代码、重算、修正方法、一个针对性实验、收窄主张、合并重复或移动完整矩阵；不要只写“实验不够”。区分必须解决的实质错误、影响解释的缺口和局部呈现问题，不伪装成编辑评分。

在看新结果前记录比较范围、数据、指标、预算和停止条件。已看测试不能改名成未见确认集。保留有效负结果和旧版本；修复无效实验不等于删去不利实验。修订完成后独立核对数字、范围及因果词，重建并查看实际最终PDF。
