## 2. Five Recurring Anti-Patterns in Rejected / Draft Industrial Figures

1. **Equal-Weight Rainbow Boxes**: Giving 5 different subsystems 5 thick saturated border colors (`blue`, `green`, `orange`, `purple`, `red`) destroys visual hierarchy—the reviewer cannot tell what is novel versus commodity.
2. **Text-Dump Microservice Shelves**: Stuffing 3–4 dense sentences + repo LOC + unit test counts + port specs into every rectangle makes the figure read like an internal ops wiki rather than a research systems architecture.
3. **Missing Concrete Data/Query Flow**: Drawing abstract boxes (`Parser -> Gateway -> Planner -> Warehouse`) without showing *what actually transforms* (e.g., NL question $\rightarrow$ typed spec $S$ $\rightarrow$ ADS/DWS/DWD gate check $\rightarrow$ Certified KPI vs. Diagnostic/Refusal).
4. **Identical Shapes for Different Ontologies**: Using the same rounded rectangle for a StarRocks database, a Redis snapshot cache, an LLM model, a decision gate, and an output verdict.
5. **Cramped Single-Column Multi-Panels**: Squeezing 2 charts side-by-side into `3.33 in` collapses tick labels below 6 pt and forces awkward rotated labels; use full-width `figure*` (`7.0 in`) or vertical stacking.
