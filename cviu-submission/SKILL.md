# CVIU submission preparation

Read [verified requirements and sources](references/requirements.md) for CVIU-specific details. Last full verification: 2026-11-05. Recheck the current official journal guide before packaging; citation/reference style and AI/data policies may change. Do not substitute another Elsevier journal's requirements or a commercial template page.

## Workflow

1. Establish article identity, version, destination, prior submission status, and authorized stage. If the user requests plan approval before editing, produce the concrete revision plan and material inventory first; leave manuscript sources unchanged until approval. Do not infer rejection from a major-revision decision.
2. Build a source-backed requirements matrix, distinguishing required, encouraged, and unverified. Record precise URL, read date, access method, and any inaccessible source. A public submit link is not a test of the logged-in submission workflow.
3. Inspect the manuscript and assets, then report separately: changes executable from existing evidence; author metadata/declarations requiring confirmation; calculations or experiments requiring data. Improve framing without hiding facts that change a scientific claim, comparison, reproducibility, or mandatory declaration.
4. Once editing is authorized, prepare the editable manuscript in the journal-linked official template, source/bibliography/artwork, highlights, declarations, data statement, and relevant supplementary files. Cover letter and graphical abstract may be useful but are not established mandatory items from the 2026-11-05 guide. Keep authored content separate from untouched publisher template assets.
5. Check abstract/keyword/highlight limits, citations, figure/table ordering and readability, editable math/tables, source compilation, factual agreement across abstract/main/supplement/cover letter, and truthful author-approved declarations. Review the rendered PDF, not only the source. Avoid inventing author roles, funding, release URLs, experimental results, or success claims.
6. If upload is authorized, use the journal's current submit link; reconcile actual fields and file designations, inspect generated proof, and resolve missing required materials. Final submission, public data/preprint release, or communication must stay within the user's authorization. Report actual completed actions and exact remaining prerequisites.

## High-value CVIU distinctions

- Single anonymized review; retain author identity. Word single-column; LaTeX may use one or two columns.
- Abstract ≤250 words;1–7keywords; required separate editable highlights:3–5bullets,≤85characters each including spaces.
- Current guide links CAS, with cas-sc/cas-dc; use target author–year citations although any consistent complete reference format is allowed initially.
- Data policy is OptionC, not merely a general encouragement. Required declarations tool Word output, CRediT, funding/AI statements as applicable, and requested ≤100word author biographies/photos belong in the material inventory.
- Graphical abstract is encouraged. Current AI policy distinguishes explanatory diagrams from research evidence and prohibits general-purpose generative-image tools for graphical abstracts.
- No explicit main-text page/word cap or mandatory cover-letter length was found. Mark live-system requirements as unverified instead of guessing.

When a DataHub policy is active, map relevant reusable sources before access and register new source interfaces through its canonical mechanism; never modify generated catalog/skill files as source of truth. Save non-secret evidence and authorized backups where the user requested. Do not publish manuscript-specific material inside a reusable public skill.
