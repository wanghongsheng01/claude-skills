# 双栏论文页面排版原则（CCF-A 数据库方向：PVLDB / SIGMOD / ICDE）

本清单讲"整页"排版：栏里有没有大块空白，浮动体（图、表、算法）放在哪，末页是否平衡，有没有越界。图里画得对不对（线穿框、图例压数据、字号）归 `ccfa-figure-layout-review` 管，两者配合使用。

**适用范围：** 用 ACM `acmart`（sigconf，PVLDB 加 `pvldb.sty`）或 IEEE `IEEEtran` 的双栏论文。
**判定对象：** 只判 Overleaf 编出的 pdfLaTeX 版本，不用 XeTeX/tectonic 的版本：后者字体、断行、浮动体位置都可能不同。
**数字只能来自正文原值。** 排版修复只做五件事：挪浮动体、换宽度、改放置参数、重排文字、缩短图注里的叙述。**不改任何实验数字，不删结果，不超页数。**

## 1. 红线 L1–L10

严重度：**blocker**＝审稿人一眼就看到，投稿前必须清零；**major**＝必须修；**minor**＝顺手修。

### L1 正文页的栏内大块空白
- **规则：** 非末页、非浮动体专页上，任何一栏不得有 ≥ 72 pt 的连续空白（不算正常的段落、标题、浮动体间距）。
- **严重度：**
  - 空白 ≥ 25% 栏高为 blocker，≥ 15% 为 major，72 pt 到 15% 为 minor。
  - 例外：参考文献或附录从下一页**顶部**开始时，前一页的栏底空白降一级。
- **依据：** 42 篇 PVLDB 正式版正文中部空洞为 0；全语料只有 3 例，都在附录或参考文献前。
- **典型成因：**
  - `\FloatBarrier` 或 `\clearpage` 放在一个 `table*`/`figure*` 还没排出去的位置，LaTeX 只能把当前页剩下的栏清空，再把通栏浮动体放到下一页顶部。
  - `[h]`/`[H]` 浮动体太大，放不进当前栏。
  - 大量浮动体在队列里等待，正文被迫推迟。
- **修法（按优先级）：**
  1. 删掉造成空洞的 `\FloatBarrier`/`\clearpage`。
  2. 把等待中的通栏浮动体的源码挪到它首次被引用的那一段**之前或之后紧邻处**，放置参数用 `[t]`。
  3. 改宽度：通栏表能压进单栏就改成单栏，单栏放不下的改通栏。
  4. 缩短图注里的叙述（不动数字）。
  5. 重排文字，例如把一个段落移到相邻小节。
- **禁止：** 用 `\vspace{-…}` 或 `\enlargethispage` 硬填。

### L2 栏顶空白
栏顶起始处出现 ≥ 72 pt 空白，常见于 `[b]` 浮动体或分栏断点异常。阈值和修法同 L1。

### L3 浮动体专页填不满
- **规则：** 整页只有浮动体时，竖向填充必须 ≥ 60%。只放一个小浮动体的专页是 blocker（填充 < 35%），35–50% 为 major。
- **依据：** 757 页里只有 3 页是浮动体专页，填充 84–97%。
- **成因：** 单个浮动体超过 `\topfraction`（0.7）或 `\dbltopfraction`（0.7），只能单独成页；或者用了 `[p]`。
- **修法：** 把浮动体压到 0.7 页以内（拆表、改宽度、缩短图注），或与相邻浮动体合并成一页；不要改 `\floatpagefraction` 来"放行"。

### L4 浮动体离引用太远，或从未被引用
- **规则：**
  - 浮动体放在首次引用的**同页或后 1 页**。
  - 晚 2 页为 minor，晚 ≥ 3 页为 major。
  - 早于首次引用 1 页为 minor（已发表论文中 8.9% 如此，但都在跨页对开处）。
  - 正文从未用 `\ref` 引用过的图表一律 major。
- **依据：** 已发表论文 86.9% 在同页或后 1 页，晚 ≥ 3 页只有 2.4%。
- **修法：**
  - 把浮动体源码移到首次引用段落之后（`scripts/floatmap.py` 列出"定义行 − 首次引用行"），放置参数用 `[t]`。
  - 如果首次引用是一句前瞻性提及（例如在方法节写"见表 9"），改成在实验节首次真正讨论处再引用，前面的提及改成"§6.3"。
  - 未引用的表格补一句引用（"Table 7 reports …"）；确实不需要的表格交作者决定是否删除，不能自行删除结果。

### L5 禁用的 LaTeX 手段
以下手段命中即 major（源码扫描）：
- 负 `\vspace`；
- 修改 `\textfloatsep` / `\floatsep` / `\intextsep` / `\dbltextfloatsep` / `\abovecaptionskip` / `\belowcaptionskip` / `\columnsep` / `\textheight`；
- `\renewcommand{\baselinestretch}{<1}`；
- 加载 `savetrees` / `geometry` / `titlesec` 改版式；
- 正文中间用 `\clearpage` / `\newpage`；
- `[H]`。

`\FloatBarrier` 和单独的 `[h]`/`[h!]` 记 minor，但一旦造成 L1 空洞就按 L1 判。

依据：
- PVLDB Vol.20 要求"no margin or spacing hacks"；SIGMOD 2027 要求页边距、栏距、行距不变，违反即 desk reject。
- 13 篇录用稿源码：`\FloatBarrier` 0/13；浮动参数改动 0/13。

### L6 末页不平衡
- **规则：** 末页（通常是参考文献）两栏底部落差 ≤ 10% 栏高。落差 > 50% 为 major，25–50% 为 minor。只溢出几行到新一页（使用率 < 12%）为 minor。
- **依据：** PVLDB 42/42 平衡。
- **修法：** acmart 文档类加官方选项 `pbalance`，即 `\documentclass[sigconf,pbalance]{acmart}` 或 `[sigconf,nonacm,pbalance]`。2026-11 在 4 份 acmart 双栏稿上实测：落差从 50–92% 降到 0–3%，页数不变。默认的 `balance` 宏包遇到末页有浮动体或参考文献很长时常常失效。IEEEtran 用 `\IEEEtriggeratref{N}` 或 `balance` 宏包。不要手动插 `\newpage` 来平衡。

### L7 越界
- 正文区外的文字超过 3.5 pt：超过 6 pt 为 major，其余 minor。
- 左栏内容伸进栏间距并与右栏正文同高：major。
- 日志里 `Overfull \hbox` > 1 pt：> 5 pt 为 major，其余 minor。

修法：给长标识符加断点（`\allowbreak`、`\path`），把表格列宽改成 `p{}` 并配 `\raggedright`，或者改用通栏。不要用 `\sloppy` 盖过去。

### L8 孤立标题与寡行
- 节或小节标题落在栏底，后面没有正文：major。
- 段落最后一短行落在栏顶（寡行）：minor。

修法：重排相邻段落或浮动体位置。不要硬插 `\newpage`。

### L9 LaTeX 浮动告警
`Float too large`、`'h' float specifier changed to 'ht'`、`Text page N contains only floats` 必须逐条看。它们往往就是 L1、L3 的原因。

### L10 交付的必须是 Overleaf 实际编出的那份
Overleaf 项目的 Main document 必须指向投稿稿件，不能是旧版 `main.tex`。审稿时先确认 Overleaf 主文档；本地编译只作为 Overleaf 编译结果的代理。主文档指错按 major 判。

## 2. 风格规则 P1–P12（来自已发表论文的统计）

- **P1 放置参数默认 `[t]`。** 已发表论文 61% 的浮动体在栏顶。
  - 单栏浮动体可用 `[tb]`。
  - `figure*`/`table*` 只能 `[t]`。不要为了把通栏放到页底而引入 `stfloats`，已发表论文页底通栏几乎没有。
  - `[h]` 只用于很小、紧跟上下文的浮动体，不要单独写 `[h]`，至少写 `[ht]`。
- **P2 宽度选择。** 约 78% 的浮动体是单栏宽。下列情况才用通栏：
  - 表格 ≥ 8 列，或单栏下要缩到 < 7 pt 才放得下；
  - 主结果表；
  - 一张横向流程图。
  算法框一律单栏（0/35 通栏）。单栏表折行严重时，优先删次要列或拆表，再考虑通栏。
- **P3 每页浮动体 ≤ 4 个**（p95 = 4）。连续两页每页都塞 3 个以上通栏表，是审稿人眼中"表格堆砌"的典型画面。
- **P4 源码位置：** 浮动体定义写在首次引用段落之后紧邻处。不要把所有表集中在实验节末尾，也不要在 `\input{tables/...}` 里统一放到节尾。
- **P5 图注长度：** 中位数约 10 词，p90 约 35 词。超过 50 词（p95）的图注把协议细节移回正文，图注只保留"结论句 + 必要的读表说明（粗体最佳、下划线次佳、W/T/L 的含义）"。图注是浮动体高度的一部分，图注越长，越容易出现 L1、L3。
- **P6 主结果表** 放在实验首节、首次引用的那页顶部（`[t]`），Takeaway 紧跟在讨论该表的段落里。
- **P7 不改浮动参数。** `\topfraction=.7`、`\bottomfraction=.3`、`\textfraction=.2`、`\floatpagefraction=.5`、`\dbltopfraction=.7`、`\dblfloatpagefraction=.5`、`topnumber=2`、`dbltopnumber=2` 保持 LaTeX/acmart 默认（录用稿源码 0/13 修改过）。放不下就改浮动体本身。
- **P8 `\FloatBarrier` 不进正文。** 确实需要"浮动体不跨节"时，用 `placeins` 的 `[section]` 选项也要先看 L1。最好的办法是把浮动体定义挪到正确位置。
- **P9 第 1 页：** 两侧作者块行数相差太大时，右栏会空出一块（不计入 L1）。可把单位缩写成两行，或者把两位作者合在一个 `\author` 块内。
- **P10 参考文献溢出页：** 末页只有一两条参考文献时（L6 minor），PVLDB 的参考文献不计入 12 页，可以接受；SIGMOD 工业轨的 12 页同样不含参考文献。但不要为了收回这一页而压缩 `\bibsep` 到 0 以下。
- **P11 修复顺序：** 先删屏障，再挪浮动体源码，然后改宽度，再缩图注叙述，最后重排文字。每改一处就重编、重跑 lint，确认没有引入新空洞，页数没超。
- **P12 审稿人和修复者必须是两个不同的 agent**（与 `ccfa-figure-layout-review` 相同）：审稿人只读，输出 `reviews/<paper>_layoutreview_rN.md`；修复者执行；审稿人在新 PDF 上复审，直到 0 blocker、0 major 才交给作者。

## 3. 审稿人步骤

1. `git pull`，用 `git archive HEAD` 导出 Overleaf 当前版本，在临时目录里用 pdfLaTeX（`latexmk -pdf`）编译。确认 Overleaf 主文档（L10）。如果能拿到 Overleaf 在线编出的 PDF，以它为准。
2. 运行 `python3 scripts/layoutlint.py main.pdf out/ --log main.log --tex <src>`：
   - 读 `out/layoutlint.md`；
   - 打开 `out/overlays/page-NN.png`：红色为空洞，蓝色为浮动体框，紫色为越界；
   - 每一条都对照页面确认，lint 只提供线索，最终靠人眼判定。
3. 运行 `python3 scripts/floatmap.py main.tex`，找出"定义在首次引用很远之后"的浮动体，以及屏障和 hack 所在的行。
4. 每页 ≥ 100 dpi 过一遍（缩略图拼成一张也可以），找出 lint 没测到的问题：浮动体内部大块留白、表格挤在页底等。
5. 每条意见写明：
   - 规则编号、页、栏、严重度；
   - 具体修法：哪个浮动体（label 加源码行）、移到哪里、放置参数、宽度、哪一段重排；
   - 预计效果：页数不变或减少。
   能在临时副本上验证的修法（例如删 `\FloatBarrier`、加 `pbalance`）先验证，并注明"已在临时副本验证"。
6. 只读，不改稿。修复者完成后复审，直到 0 blocker、0 major。

## 4. 已验证的修法实例（匿名）

- **右栏下半页空白：** 一篇 11 页稿第 9 页右栏 66% 空白，成因是讨论节之前的 `\FloatBarrier` 卡住了一个尚未排出的 `table*`。注释掉这一行重编后空洞消失，全文从 11 页缩到 10 页，数字未动。
- **末页参考文献左满右空：** 4 篇 acmart 双栏稿，落差 50–92%。加文档类选项 `pbalance` 后落差降到 0–3%，页数不变。
- **结果表晚 4–5 页才出现：** 表格都用 `\input{tab_*.tex}` 集中放在实验节末尾，而首次引用在 3–5 页之前。把 `\input` 移到首次讨论的段落之后，用 `[t]`。
- **方法节里前瞻引用结果表：** 方法节写"见表 3"，而表 3 属于实验节。表格被提前"首次引用"，导致它晚 4 页才出现。改成在方法节写"§6.3"，在实验节首次讨论时引用表格。
