# 模型级性能改进的审阅

承接 [性能主张的核查](performance-claims.md)，用于表示、几何或外观模型的新增主张。只处理影响当前结论的问题，不把下表当成每篇论文必做的实验矩阵；这些是研究审阅建议，不是期刊规定。

## 先辨认真正的比较对象

核对最近邻原文、作者提交和运行版本。把作者报告、完整方法重跑、设备移植、共同骨干上的 RGB 核心对照分开命名；不能将一个颜色函数的移植写成击败完整方法。反过来，完整方法总分也不能单独证明某一模块的原因。资源不足可以限定比较范围，不能通过减少外部方法的关键组件制造弱基线。

公共例子：[GStex（WACV 2025）](https://openaccess.thecvf.com/content/WACV2025/papers/Rong_GStex_Per-Primitive_Texturing_of_2D_Gaussian_Splatting_for_Decoupled_Appearance_WACV_2025_paper.pdf) 研究 per-primitive 纹理；[Textured Gaussians（CVPR 2025）](https://openaccess.thecvf.com/content/CVPR2025/papers/Chao_Textured_Gaussians_for_Enhanced_3D_Scene_Appearance_Modeling_CVPR_2025_paper.pdf) 也提供空间纹理表示。因此“比标准视方向颜色更好”本身不足以建立空间外观机制的新颖性或完整 SOTA 竞争力。例子不是所有视觉任务的必跑清单，须先核任务、输入条件与实现可用性。

## 发现转成最小闭环

| 实质发现 | 具体动作 | 最小证据与完成标准 |
|---|---|---|
| 核心移植被标作完整近邻 | 修正比较名与保留/省略模块表；若保留完整方法胜负主张，再补适配的完整运行 | 结果能追溯到实际版本；主张与所执行范围一致 |
| 只有参数数相等就称容量或公平性等同 | 分列函数族、自变量/支持域、激活、可学习/固定参数与共享部分 | 能看出控制了什么；不把参数计数当函数容量证明 |
| 前向公式看似相同，求交、无交点、射线或激活未核 | 查固定作者源码及真实反向路径，定位差异；对有关边界做针对性数值检查 | 有可复核的函数合同与适配说明；不是仅凭成功导入判定等价 |
| 相同初始图像掩盖不同优化历史 | 核共同预热、参数映射、Adam 矩/step、采样与调度；按实际研究问题选择恢复或共同重置 | 明确哪些状态匹配；若保留不同配方，不把差异全归因于模型 |
| 训练指标改善而 held-out 退化被省略 | 恢复固定检查点的完整曲线和端点；核实现后选择能区分解释的最小对照 | 训练与泛化方向都可见；不把仅相容于过拟合的现象写成已证实原因 |
| 固定几何的颜色改进被推成联合几何能力 | 收窄结论，或补必要的几何×外观配对 | 直接比较支持相应范围；图像指标不冒充几何真值 |
| 同更新数被写成同计算预算 | 分开报告更新、容量、时间/内存及额外预热、探针或试渲染开销 | 主比较条件透明，成本与具体运行对应 |
| 用有利场景或相关性解释普遍收益 | 恢复全矩阵与反例，标明条件选择时间；需要因果时补相关受控干预 | 完整效应与单位可重算，观察/相关/干预的解释层级清楚 |

每项结论仍须补上原文位置、受影响主张、实施版本与证据路径。已有证据能解决时优先重算、改标签或改写；不要把所有发现都升级为新训练要求。有效负结果不能因更换叙述而消失。

## 源码与结果范围的最后核对

[Textured-GS 作者版本](https://arxiv.org/html/2407.09733v3) 的固定 [前向](https://github.com/ZhentaoHuang/Textured-GS/blob/06950fe2777efa9bc5e4dea26d95670ace04daae/submodules/diff-gaussian-rasterization_texture/cuda_rasterizer/forward.cu) 和 [反向](https://github.com/ZhentaoHuang/Textured-GS/blob/06950fe2777efa9bc5e4dea26d95670ace04daae/submodules/diff-gaussian-rasterization_texture/cuda_rasterizer/backward.cu) 可以说明为什么求交根、无交点分支、局部坐标、激活与梯度必须对照实际代码。本参考仅将它作为作者版本和代码证据，不赋予未核实的正式发表状态，也不要求所有方法采用同一边界规则。

最后核对三件事：独立目标是否在选型中用过；配对身份和场景/种子/相机/帧层级是否保持；结论是否同时容纳主要端点、感知/时间端点和成本的真实权衡。得到小幅或混合结果时，检查证据与主张是否对应，而不是预设必须胜出，或未经不确定性分析就宣称等价。所有新增与替代实验均应有有界预算及与发现对应的关闭条件。
