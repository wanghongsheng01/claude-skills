# 公开依据与适用边界

复核日期：2026-11-07。以下是公开出版商规则与作者预审方法，未获得 CVIU 内部审稿表、保密审稿意见、录用因果或录取率。

## 来源与层级

- [CVIU Guide for Authors](https://www.sciencedirect.com/journal/computer-vision-and-image-understanding/publish/guide-for-authors)：期刊具体要求优先。2026-11-05 有完整浏览器快照；2026-11-07 注册的 DataHub GET 与 web 直读均为 403，不能称当日全文更新核验。单匿名审稿等期刊细节仍标明来自该历史快照；最新可达时复核。
- [Elsevier How to conduct a review](https://www.elsevier.com/reviewer/how-to-review)：2026-11-07 官方全文通过注册 DataHub GET 和公开 web 阅读。其原始研究部分要求对照题名、摘要、研究目标、可复现方法、统计、图表、解释和引文；允许指出需要的附加分析与敏感性证据。具体评论应有事实依据，说明为何影响判断；编辑作最终决定。这是通用审稿建议，临床举例与综述类型的专属条目不自动适用于视觉算法论文。它并未禁止作者在投稿准备阶段开展补充或替换实验。
- [Elsevier journal AI policy](https://www.elsevier.com/about/policies-and-standards/generative-ai-policies-for-journals)：2026-11-07 官方全文可读。作者自有稿件的 AI 辅助写作与受邀评审他人保密稿件不同。不得把第三方保密稿件或其部分上传 AI；受邀审稿人承担独立科学判断，允许的辅助用途仍须满足隐私、人类控制和披露条件。
- 正式发表论文及其作者版本可用来观察研究组织与证据表达；必须区分版本和可读范围。样本不提供匿名审稿人的真实决定原因，也不建立某种措辞能确保录用的结论。

## 本技能原创的操作方法

贡献—证据地图、P0/P1/P2工作分级、六类实验调整、行动卡和完成标准是面向作者的研究修订方法，不是期刊硬性评分。允许增加证据，也允许以充分现有证据重组文字或收窄主张；必要性由具体科学问题决定。

将重复自贬合并为紧凑的适用范围，强化研究问题和有证据的结论。对读者判断有影响的条件、不利指标、反例、监督差异和无效比较仍应清楚交代。无需写入每一项未开展的无关实验；也不能隐瞒已知的材料性问题。任何未来改进都不得预先写成已验证结果。
