# CVIU 作者预审与修订指导

先准确复述论文最有证据的贡献，再判断哪些发现会改变读者对它的理解。审查应帮助改进研究和呈现，不预测录用率，也不把所有可探索的问题升级为必做实验。依据与适用边界见 [公开审稿依据](references/public-review-basis.md)。

## 版本与任务边界

记录当前稿、数据/代码版本、历史投稿状态。区分作者报告、本次重算、代码核验与推断；引用具体页、节、表或源文件。复用已经确认的作者事实，不把作者自审权限推广为处理他人的保密期刊审稿材料。

根据用户当前授权开展工作。若要求先交计划，完成具体计划后保持论文和实验不变；批准后可执行获授权的修订与增量实验。这个技能不把审查限定为措辞润色，也不自行扩展为无期限实验项目。

正式指南、出版商通用建议、已发表论文观察、自己的研究判断须分别标明。可使用 `cviu-submission` 核实投稿要求、`write-cviu` 学习正式论文组织；不要把样本写法当作硬性格式。存在 DataHub 常设规则时先映射对应模块，新来源按当地流程登记。

## 贡献—证据地图

用一段话复述输入、输出、研究设置、视觉问题、机制、主要发现与适用范围。为每个贡献定位公式、图表和支持实验，再检查：

- **任务和意义**：标题、摘要、监督信息、训练/测试输入及评价是否描述同一任务？图像渲染改善不自动证明几何准确、跟踪或未见时间泛化。
- **最近邻差异**：从原始论文和作者源码核对已有机制。区分完整外部方法、共享骨干上的策略移植、自有简单对照。不能把改名当新机制，也不能仅因共享模块否定组合或机制研究的价值。
- **实现定义**：符号、形状、归一化、梯度、图构造、随机采样、边界和更新时机是否与运行版本一致？有矛盾先定位代码/配置，不靠文风决定公式。
- **公平对照**：数据划分、几何/姿态/深度先验、额外监督、初始化、分辨率、容量、更新次数、运行时间、调参与评估代码是否透明？分别陈述所控制因素，不能将同更新次数称为同运行成本。
- **机制和归因**：关键主张是否需要模块消融、竞争解释对照、同状态干预或简单替代？一次选点变化、操作后扰动与优化后质量是不同证据，不能混作因果链完成。
- **统计单位**：识别人、动作、场景、相机、帧和种子的嵌套关系，使用实际配对数据。不能用帧数充当独立重复，不从汇总均值还原样本；同初始状态也不自动保证硬件数值重放一致。
- **完整发现**：保留主要指标、负结果、反例和材料性条件。零/负结果与机制分析可以支持限定的科学贡献，无需虚构胜出。解释差异大小和不确定性；没有相应证据不使用显著、等价、普遍优越等结论。
- **图文组织**：实验图采用可比视角、时刻、尺寸与处理；标明指标、单位及选择规则。正文先回答核心问题，将重复表述与次要完整矩阵移至补充并保留清晰引用。发表样本只提供组织经验，不能推出审稿人的因果偏好。

涉及同状态干预、移植实现或复现实验时，进一步核对三点：计算顺序是否与原浮点代码一致，而不仅是公式代数等价；不同种子的初始化变化与同种子重放差异是否分层报告；前景放大图是否由与结果无关的统一规则生成、可定位到完整视图，并与前景掩码指标明确区分。这些检查用于解释实际比较，不自动要求每篇论文补做重放实验。

## 将发现转成动作

每项实质发现都输出以下链条：

**发现及原文位置 → 对主张的影响 → 具体动作 → 最小证据 → 完成标准 → 版本与改动记录。**

动作可以是新增实验、补充测量、替换不公平/无效设计、合并重复实验、移至补充、删除冗余呈现，也可以是重算、修正方法或收窄结论。选择依据是它能否解决一个明确问题，而不是默认更多实验更好。具体决策与例子见 [实验与证据动作表](references/revision-actions.md)。

使用工作优先级而非冒充期刊评分：

- **P0**：已证实的方法/数据/计算矛盾，误导性核心主张，或违反核实的投稿要求；明确关闭条件。
- **P1**：影响主要解释或有竞争力比较的实质缺口；说明需补证，还是现有证据支持收窄主张即可。
- **P2**：组织、措辞与局部图表问题；避免把累积小修包装成科学失败。

为计划标记实施类型：现有证据即可改、需代码/配置核对、需原始测量重算、需新实验、需缺失作者事实。给出可检验的完成条件，例如某一对照能排除指定解释、同一数据分母可重算一致、修订表包含所有预先声明条件。不要只写“加强实验”。

## 实验调整与结果完整性

在看到新结果前记录研究问题、对照、预算、输入/划分、指标、聚合、纳入规则和停止条件。已看过的测试结果不能因改文件名再次称为未见测试；后续改进如继续使用这些结果，明确其探索性质，或另设真正未使用的确认数据。

保留旧版本与替换理由；替换无效实验不等于把有效但不利的实验删去。合并或移至补充应保留解释所需的完整结果和正文指向。只有重复、无关、无效或已被明确等价内容覆盖的呈现才适合删除；不能用删除负结果或问题表格来制造“问题已关闭”。

为每项变更记下原版本、新版本、实现差异、受影响图表/主张、数据和指标版本、完成证据，以及未变的比较范围。新结果若不支持原假设，修改解释或主张，不反复挑数据、种子、指标直至出现利好。

## 交付

交付有依据的贡献概括、按优先级的行动表、最低必要修订顺序及可选增强项。分开写科学证据状态与文件/格式状态；只对已核实完成的项目标记通过。删除空泛自贬、合并重复边界，让事实支持的研究发现成为主线，同时保留决定读者解释的条件。未经授权，不提交论文、发布数据或发送审稿报告。
